为什么超越浏览器 PWA

针对长期日常听歌中遇到的真实痛点逐项加固，而非简单套壳。

01. 会员权益与安全直登

完整保留 YouTube Premium 体验

不走任何第三方破解接口，官方账号直接登录。登录域名自动切换兼容 UA 并净化风控头，另提供剪贴板 Cookie 同步兜底方案。

02. 菜单栏迷你控台

专辑封面与音量随时触达

点击 macOS 顶部状态栏图标弹出迷你播放器，直接查看封面、拖拽进度、切歌并调节音量。

03. 播放防中断

后台防休眠与自动恢复

阻止 macOS App Nap 节流，放行 DRM 权限，自动确认「您还在收听吗？」弹窗并在断流时恢复播放。

04. 原生导航守卫

常驻返回按钮，永不迷失在未知页面

左上角常驻返回、前进、刷新与首页按钮，支持双指滑动返回；帮助页及非音乐外链自动转交系统默认浏览器打开。
